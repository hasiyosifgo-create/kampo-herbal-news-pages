# Antigravityエージェント用構築指示

以下をAntigravityの新規プロジェクトに対する最初の指示として使用してください。

```text
このリポジトリ内の antigravity/migration-manifest.json を唯一の移植仕様として読み、漢方・生薬ニュースサイトをゼロから実装してください。既存の画面実装は参照せず、データと仕様のみを移植元として扱います。

目的は、日本漢方生薬製剤協会の会員企業55社を対象に、漢方・生薬に関する公式ニュースを表示する日本語のレスポンシブWebアプリです。初期データは docs/data/news.json を読み込み、会員企業の公式情報源は member-sources.txt を正規化して利用してください。

必須機能:
1. 新発売、回収、中止・終了、店舗ニュース、一般ニュースを別カテゴリで表示し、色・ラベルを明確に分ける。
2. 新発売にはメーカー名、製品名、公式告知日、発売日が明示的に取得できた場合のみ発売日、公式詳細リンクを表示する。公式告知日と発売日を混同しない。
3. 各記事は公式URLを安定した一意キーとして扱い、同一の公式告知を重複表示しない。
4. 記事の既読状態は端末・ブラウザごとにローカル保存し、既読化、未読へ戻す、未読のみの絞り込みを実装する。
5. 会員55社・公式監視52社・PMDA補完3社のカバレッジと、直近24時間の確認成功・失敗件数を表示する。
6. 化粧品、サプリメント、健康茶、漢方・生薬と無関係な一般企業ニュースは新発売・回収・中止終了に混入させない。
7. 複数画面幅で読みやすく、記事タイトルは最大2行で省略する。公式詳細リンクは常に新しいタブで開く。

更新処理:
- scripts/github-pages-crawl.mjs のポリシーを参考に、公式情報源を3グループへ決定論的に分割し、1回の更新で1グループだけを確認する。
- 収集結果は安全に保持し、取得失敗時に直前のデータを削除しない。
- 更新頻度はプラットフォームのスケジュール機能が許容する範囲で高頻度に設定する。正確なリアルタイム実行を保証しないことを画面または管理情報に明記する。

実装を始める前に、migration-manifest.json と docs/data/news.json のスキーマを確認し、データモデル、画面構成、更新フローを短く提示する。その後に実装し、分類・日付・公式URL・既読状態をテストで検証する。
```
